Start: chưa chọn

Goal: chưa chọn

Click vào một nút để đặt Start, click nút tiếp theo để đặt Goal.

Chú thích

  • Đường bình thường
  • Đường ngập (trọng số ×10)
  • Đường tắc (trọng số ×50)
  • Node đang xét
  • Node đã duyệt
  • Frontier / Open set
  • Đường kết quả

Các cạnh được tạo mẫu từ khu vực Khương Đình. Bạn có thể thay thế file backend/khuong_dinh.graphml bằng dữ liệu OSMnx thực tế để trực quan hóa bản đồ thật.
